# Sumit Bhamu — Portfolio

Personal portfolio website of **Sumit Bhamu**, a Graphic Designer and Visual Creator, showcasing event posters, social media creatives, branding assets, and digital design work.

🔗 **Live Demo:** (https://nexus-sumit.vercel.app/)

## 🎨 About

This is a fully responsive, single-page portfolio built with plain HTML, CSS, and JavaScript — no frameworks or build tools required. It highlights:

- Selected design work (posters, social media creatives, branding, campaigns)
- Design skills and tools (Canva, Photoshop, Illustrator, Figma, Premiere Pro, After Effects)
- Design experience and leadership roles at Team Next Nexus (TNN), VIT-AP University
- Selected events and campaigns designed for hackathons, workshops, and recruitment drives

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS3** — styling, layout, and animations
- **JavaScript (Vanilla)** — interactivity and custom cursor effects
